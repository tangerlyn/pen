## 콘텐츠·발견

| 기능 | 설명 | 난이도 | 상태 |
|---|---|---|---|
| 아카이브 정렬 옵션 | "별점 높은 순"(비활성화됨), "리뷰 많은 순"(인기순). `avgRating/reviewCount` 필드 이미 있음 | 쉬움 | ⏸️ (별점순은 별점 시스템 비활성화로 숨김) |

| 해시태그 | 리뷰/게시글 태그 달기 → 태그 탐색 피드 | 보통 | - |
| 큐레이션 컬렉션 | 에디터 선별 "이달의 잉크", "입문자 추천 만년필" 목록 | 보통 | - |
| 카메라로 잉크 색 검색 | 실물 색상 촬영 → 유사 잉크 검색 | 어려움 | - |
