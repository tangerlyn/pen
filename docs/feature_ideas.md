# 기능 아이디어 목록

## 소셜·커뮤니티

| 기능 | 설명 | 난이도 | 상태 |
|---|---|---|---|
| 게시글/리뷰 외부 공유 | 링크 복사 or 카카오 공유. `share_plus` 패키지 | 쉬움 | 구현 완료, 당장 불필요해 주석 처리 |
| 댓글 멘션 (@닉네임) | 댓글에서 유저 태그 + 알림 발송 | 보통 | - |
| 커뮤니티 게시판 세분화 | 현재 질문/정보공유 2개 → 장터(중고거래), 사진자랑, 모임 등 추가 | 쉬움 | - |
| 팔로잉 활동 피드 | 팔로잉 유저가 좋아요/댓글/잉크 추가한 활동 스트림 | 보통 | - |
| 뱃지/업적 시스템 | "첫 리뷰", "잉크 50종 수집", "팔로워 100명" 등 | 보통 | - |
| 팔로우 추천 | 관심 브랜드/활동이 비슷한 유저 추천 | 보통 | - |
| 오픈채팅방 | 잉크/브랜드 주제별 단체 채팅 | 어려움 | - |

| 기능 | 설명 | 난이도 | 상태 |
|---|---|---|---|
| 스와치 메모 뷰 | `InkChartModel.memo` 필드가 이미 있는데 UI 없음 | 쉬움 | - |
| 잉크 색상 비교 | 2~3개 잉크 헥스 색상 나란히 비교 (`ink_compare_screen.dart` 구현 완료) | 쉬움 | 구현 완료, 적용 보류 |
| 위시리스트 | 갖고 싶은 잉크/만년필 목록 | 쉬움 | ✅ |
| 종이(Paper) 탭 아카이브 | `PaperModel`이 이미 정의되어 있는데 아카이브에 탭 없음 | 보통 | - |
| 잉크 소진/보유 상태 관리 | 미개봉 / 사용중 / 소진 상태 추적 | 보통 | - |
| 잉크-만년필 페어링 기록 | 어떤 펜에 어떤 잉크를 넣었는지 기록 | 보통 | - |
| 잉크 차트 공개 공유 | 공개 전환 + 타 유저 차트 탐색 | 보통 | ✅ |
| 유사 잉크 색상 추천 | 아카이브 상세에서 "이 잉크와 비슷한 색" 추천 (헥스 유사도) | 보통 | - |
| 필사 일지 | 날짜별 사용 잉크·펜·종이 조합 기록 | 보통 | - |

## 콘텐츠·발견

| 기능 | 설명 | 난이도 | 상태 |
|---|---|---|---|
| 아카이브 정렬 옵션 | "별점 높은 순", "리뷰 많은 순". `avgRating/reviewCount` 필드 이미 있음 | 쉬움 | ✅ |
| 인기 잉크 랭킹 | 이번 주 리뷰 많은 잉크 Top10 | 쉬움 | ✅ |
| 가격/구매 링크 | 아카이브 제품 상세에 공식몰 or 네이버 쇼핑 링크 | 쉬움 | - |
| 해시태그 | 리뷰/게시글 태그 달기 → 태그 탐색 피드 | 보통 | - |
| 큐레이션 컬렉션 | 에디터 선별 "이달의 잉크", "입문자 추천 만년필" 목록 | 보통 | - |
| 카메라로 잉크 색 검색 | 실물 색상 촬영 → 유사 잉크 검색 | 어려움 | - |
| 개인화 추천 피드 | 위시리스트·작성 리뷰·검색어에 태그된 브랜드/색상계열/타입을 가중치로 모아 "선호 프로필"을 만들고, 추천 후보와 태그 겹치는 정도로 스코어링해 정렬 (Firestore만으로 가능한 경량 콘텐츠 기반 필터링, 진짜 협업 필터링만큼의 발견성은 없음). 아카이브 상세 조회 이벤트 기록이 선행되어야 함. 유저 수가 늘어난 뒤 재검토 | 보통 | - |
