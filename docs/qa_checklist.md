# 기능 QA 체크리스트

화면/탭별로 버튼·입력을 눌렀을 때 기대되는 동작을 정리한 수동 테스트용 확인서.
실제 코드(`lib/`) 기준으로 작성됨 — 화면 구조가 바뀌면 이 문서도 같이 갱신할 것.

---

## 로그인 / 회원가입

| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 비로그인 상태로 앱 실행 | `/login` 화면 자동 진입 |
| 2 | "카카오로 시작하기" 탭 | 카카오 OAuth → Firebase 로그인 → 기존 유저면 홈, 신규 유저면 닉네임 입력 화면 |
| 3 | "네이버로 시작하기" 탭 | 네이버 OAuth → 위와 동일 분기 |
| 4 | "Apple로 시작하기" 탭 | Apple Sign-In → 위와 동일 분기 |
| 5 | 로그인 실패(취소 포함) | 화면 중앙 팝업으로 에러 문구 표시, 로그인 화면 유지 |
| 6 | 닉네임 입력 후 "중복확인" 탭 | 사용 가능하면 초록 문구, 중복이면 빨간 문구 |
| 7 | 중복확인 안 하고 "다음" 탭 | 버튼 비활성화 상태라 진행 안 됨 |
| 8 | 중복확인 통과 후 "다음" 탭 | `/signup/profile`로 이동 |
| 9 | 닉네임 13자 이상 입력 시도 | 12자에서 더 이상 입력 안 됨 |
| 10 | 프로필 사진 화면 "건너뛰기" 탭 | 사진 없이 `/signup/interests`로 이동 |
| 11 | 관심 카테고리 미선택 상태로 "시작하기" 탭 | 선택 없이도 진행 가능(선택은 선택사항) — 유저 문서 생성 후 홈 이동 |
| 12 | 로그인된 상태로 `/login` 등 인증 화면 접근 시도 | 자동으로 홈(`/`)으로 리다이렉트 |

## 알려진 제약 / 아직 없는 기능 (QA 시 "버그 아님" 참고용)

- 채팅 메시지에는 글자 수 제한이 없음 (의도적으로 미구현 상태, 추후 검토 대상)
- 채팅방 ⋮ 버튼은 아직 기능 없음 ("추후 확장 예정")
- 외부 공유 버튼(카카오/링크 공유)은 리뷰 상세에 구현은 돼있으나 주석 처리되어 비노출 상태
- 잉크 색상 비교 화면(`ink_compare_screen.dart`)은 구현 완료됐으나 어디에도 연결 안 됨
- 공개 잉크북 "둘러보기"(`/public-ink-books`) 화면에서, 이 기능이 생기기 전에 만들어진 공책은 소유자 닉네임이 "익명"으로 보이거나 카드 클릭이 안 될 수 있음
