# 다국어(글로벌) 지원 계획 — 한국어 · 일본어 · 영어

> 상태: **계획만** (2026-11-15 작성). 출시 후 사용자 반응을 보고 착수.
> 목표: 기기 언어에 맞춰 앱 화면이 한국어/일본어/영어로 보이고, 다른 언어로 쓴 리뷰도 읽을 수 있게.

## 결론: 무료로 가능한가?

**거의 전부 무료로 가능하다.** 돈이 드는 건 "사람이 쓴 리뷰·글을 번역해 주는 기능"을
서버 번역 API로 할 때뿐이고, 이것도 기기 안 번역(ML Kit)을 쓰면 무료다.

| 항목 | 방법 | 비용 |
|---|---|---|
| 앱 화면 문구(버튼·안내) | Flutter 공식 다국어(`flutter_localizations` + ARB) | 무료 |
| 문구 번역 작업 자체 | 초안은 AI로, 일본어는 원어민 검수 권장 | 무료~소액(검수) |
| 리뷰·게시글 내용 번역 | ① ML Kit 기기 내 번역 (`google_mlkit_translation`) | **무료**, 오프라인 동작 |
| | ② Google Cloud Translation API | 월 50만 자까지 무료, 이후 $20/100만 자 |
| 앱스토어 소개 페이지 | App Store Connect에서 언어 추가 | 무료 |
| 일본어 글꼴 | Pretendard JP 또는 Noto Sans JP (둘 다 무료 라이선스) | 무료 (앱 용량 +수 MB) |

추천: 화면 문구는 공식 다국어, 리뷰 번역은 **ML Kit(무료)** 로 시작하고, 품질이 아쉬우면 그때 서버 API로.

## 현재 상태 (얼마나 손봐야 하나)

- 앱 코드에 한국어 문구가 직접 박혀 있는 곳: **약 870개 문자열, 86개 파일** (`lib/`).
- 서버 알림 문구(`functions/index.js`)도 한국어로 고정 — 받는 사람 언어로 보내도록 바꿔야 함.
- 날짜 표시("3분 전" 등, `post_date_format.dart`)도 한국어 고정.
- 잉크·만년필 이름은 대부분 영어/원어라 그대로 써도 됨. 색상 계열·충전 방식 같은 분류값만 번역 필요.

## 단계별 작업

### 1단계 — 다국어 뼈대 (보통, 1~2일)
- [ ] `pubspec.yaml`에 `flutter_localizations`, `intl`, `generate: true` 추가, `l10n.yaml` 생성
- [ ] `lib/l10n/app_ko.arb`(기준), `app_en.arb`, `app_ja.arb` 생성
- [ ] `MaterialApp`에 `localizationsDelegates`, `supportedLocales: [ko, en, ja]` 연결
- [ ] iOS `Info.plist`에 `CFBundleLocalizations` (ko, en, ja) — 없으면 iOS가 언어를 인식 못 함
- [ ] 앱 이름 현지화: 일본어/영어에서는 `MANNTI`로 (`InfoPlist.strings`)

### 2단계 — 문구 옮기기 (어려움, 분량이 많음)
- [ ] 화면별로 하드코딩 문구를 ARB 키로 교체 (`AppLocalizations.of(context).xxx`)
- [ ] 복수형·변수 문구는 ICU 형식 사용 (예: `{count}개의 리뷰`)
- [ ] 한국어 조사 처리하던 곳(`을/를` 등)은 언어별 문장으로 분리
- [ ] 날짜·상대시간을 언어별로 (`intl`의 `DateFormat`, 상대시간은 언어별 문구)
- [ ] 분류값(색상 계열·충전 방식·게시판 카테고리)은 DB에는 코드값으로 저장하고 화면에서만 번역
- [ ] 권한 요청 문구(카메라·사진)도 언어별 `InfoPlist.strings`

### 3단계 — 서버 알림 현지화 (보통)
- [ ] 로그인할 때 기기 언어를 `users/{uid}.locale`에 저장
- [ ] `functions/index.js` 알림 문구를 언어별 사전으로 분리, 받는 사람 `locale`로 선택

### 4단계 — 리뷰·글 번역 보기 (보통)
- [ ] 글 작성 시 언어 감지해서 `lang` 필드 저장 (ML Kit 언어 감지, 무료)
- [ ] 내 언어와 다른 글에 "번역 보기" 버튼 → ML Kit로 기기 안에서 번역
- [ ] 언어 모델은 처음 한 번 내려받음(언어당 약 30MB) → 와이파이에서 받도록 안내
- [ ] 품질이 부족하면 Cloud Translation API + 번역 결과 Firestore 캐시(같은 글 재번역 방지)

### 5단계 — 스토어·법적 문서 (쉬움~보통)
- [ ] App Store Connect / Play Console에 영어·일본어 소개 문구와 스크린샷 추가
- [ ] 이용약관·개인정보처리방침 영어/일본어판 (일본은 개인정보보호법(APPI) 기준 확인)
- [ ] 고객지원 페이지 영어판

## 미리 해두면 좋은 습관 (지금부터)

- 새 화면을 만들 때 문구를 한 파일(상수)로 모아 두면 2단계가 훨씬 빨라짐
- DB에 화면용 한국어 문장을 저장하지 말고 코드값(`piston`, `blue`)으로 저장
- 글꼴은 일본어 한자가 들어간 버전으로 교체할 수 있게 `fontFamily`를 한 곳(테마)에서만 지정 (현재 그렇게 되어 있음)
